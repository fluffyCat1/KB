# KBBlade

Плагин для Paper **1.21.11** (Java 21). Выдаёт особый меч по команде `/kb <id>`.

## Механика

**Прокачка урона (пассивно)**
- Убийство игрока этим мечом → атрибут урона `ATTACK_DAMAGE` увеличивается на **+2.0**.
- Убийство мирного животного (`Animals`: корова, овца, курица, свинья и т.д.) → **+0.25**.
- Бонус суммируется и хранится прямо в предмете (PersistentDataContainer), поэтому переживает рестарт сервера и переход предмета между игроками. Лор предмета показывает текущий бонус и счётчики убийств.

**Способность на ПКМ**
При правом клике с мечом в руке (если не на перезарядке):
- Невидимость на 6 секунд.
- Сопротивление уровня 255 (амплификатор 254) на 6 секунд.
- Временный атрибут прыжка `JUMP_STRENGTH` **-1** на 6 секунд.
- Временный атрибут высоты шага `STEP_HEIGHT` **+1** блок на 6 секунд.
- Игрок не может атаковать, пока действует эффект (блокируется `EntityDamageByEntityEvent`).
- Под ногами остаётся след из `BlockDisplay` (чёрный бетон), сплющенных до высоты 0.01 блока — новая пластина ставится при переходе на новый блок.
- **Через 5 секунд после активации** все заспавненные `BlockDisplay` этой активации удаляются (задача берёт список сущностей именно этой активации, а не глобально).
- Перезарядка способности — **15 секунд** (не привязана к материалу, реализована собственным таймером на игрока + сообщение в action bar с оставшимся временем).

### Важный нюанс по таймингам
Ты просил, чтобы след исчезал через 5с **после использования** способности, при этом сама невидимость длится 6с. Технически это значит, что спавн следа (и его очистка) останавливается на 5-й секунде, а невидимость доживает ещё 1 секунду без нового следа — так и реализовано, чтобы не оставлять "зависшие" пластины, которые пришлось бы досрочно обрывать посреди списка. Если нужно, чтобы след продолжал появляться все 6 секунд, а удалялся весь целиком именно на 5-й секунде (т.е. часть пластин удалялась бы раньше, чем появилась) — скажи, поправлю логику под этот вариант.

## Сборка локально

```bash
mvn -B package
```

Готовый jar появится в `target/kbblade-1.0.0.jar`. Положи его в папку `plugins/` на Paper 1.21.11.

## Сборка через GitHub Actions

В репозитории уже лежит `.github/workflows/build.yml`:
- при пуше в `main` / pull request — просто собирает jar и кладёт его в **Artifacts** запуска workflow (вкладка Actions → выбранный запуск → Artifacts);
- при пуше тега вида `v1.0.0` — дополнительно создаёт GitHub Release и прикрепляет jar к нему.

Чтобы получить релиз:
```bash
git tag v1.0.0
git push origin v1.0.0
```

## Команда

```
/kb <id> [игрок]
```
- `<id>` — произвольная строка-идентификатор, записывается в предмет и в лор.
- `[игрок]` — необязательно, если не указан — меч получает тот, кто вводит команду (должен быть игроком).
- Право на выдачу: `kbblade.give` (по умолчанию — только op).
- Право на использование способности: `kbblade.use` (по умолчанию — у всех).

## Структура проекта

```
pom.xml
src/main/resources/plugin.yml
src/main/java/com/kb/blade/
    KBPlugin.java        — главный класс, регистрация команды/листенеров
    KBKeys.java           — все NamespacedKey в одном месте
    KBItem.java            — создание меча, начисление бонуса, лор
    SwordCommand.java       — /kb <id> [игрок]
    KillListener.java        — начисление +2 / +0.25 за убийства
    AbilityListener.java      — ПКМ активация + блокировка атаки
    AbilityManager.java        — вся логика способности (эффекты, атрибуты, след, кулдаун)
.github/workflows/build.yml — сборка на GitHub Actions
```
